비밀번호 강도 검사기, 안전한 비밀번호 생성기, 그리고 k-익명성 기반 유출 여부 확인 기능을 한 화면에 담은 **비밀번호 보안 점검 대시보드 웹앱**입니다. 사용자가 직접 비밀번호를 입력하거나 안전한 비밀번호를 생성한 뒤, 버튼 클릭 한 번으로 실제 유출 사고 이력까지 한눈에 점검할 수 있도록 구성했습니다.

**Gemini 웹에서 요구사항과 기능 명세를 먼저 구체화한 뒤, Antigravity IDE에서 Implementation Plan을 검토하고 단계별로 코드를 구현**하는 협업 방식을 사용했습니다.
2. 비밀번호 "강도"의 기준을 어떻게 정했나요?
비밀번호 강도는 **길이(8자·12자 이상), 문자 종류(대문자·소문자·숫자·특수문자) 조합, 그리고 흔한 패턴(`1234`, `qwer`, 동일 문자 반복) 포함 여부**를 기준으로 5단계 게이지와 피드백이 나오도록 설정했습니다.
3. 구현 중 가장 막혔던 문제는 무엇이었고, 어떻게 해결했나요?
유출 확인 기능 구현 시, 서버 응답의 해시는 대문자인데 브라우저에서 생성한 SHA-1 해시를 소문자 상태로 비교하여 유출된 비밀번호도 안전하다고 판정되는 문제가 있었습니다. 해시 문자열을 `.toUpperCase()`로 변환해 대조하도록 수정하여 해결했습니다.

## 나만의 확장 기능

<!-- 기본 4가지 기준 외에 추가한 기능(예: Add-Padding 적용, AES 암호화 금고 탭, 흔한 패턴 감지 등)을 적어 주세요 -->
- **흔한 취약 패턴 감지:** `1234`, `qwer`, 동일 문자 반복 등 추측하기 쉬운 패턴을 감지해 강도 점수를 감점하고 경고 메시지를 표시합니다.
- **생성 비밀번호 즉시 점검 연동:** 생성기에서 만든 비밀번호를 복사·붙여넣기 과정 없이 버튼 한 번으로 강도 및 유출 검사 입력칸에 바로 적용해 테스트할 수 있습니다.
